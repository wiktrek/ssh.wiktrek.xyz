# SSH app
Try ssh'ing into this app to see what its like!
```
ssh ssh.wiktrek.xyz -p 40101
```
# How to host it yourself
1. install golang
2. Run ```go run .``` or build it using  ```go build .``` and run ```./ssh.wiktrek.xyz```
